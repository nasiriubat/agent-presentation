A chatbot is a brain in a jar

It knows a lot. It can talk. It can't touch anything.

🖐️ Give it hands: tools it can call

🗂️ Give it a notebook: memory that lasts

🔁 Give it a loop: think → act → observe → repeat

That's an agent.

Theory speaker: The one picture people should take home. Each → adds a part to the 3D jar.

Hands: "a tool is just a function the AI is allowed to call: search, calculator, send email." Notebook: "memory it writes to and reads later, across conversations." Loop: "it doesn't answer once. It tries, looks at what happened, and decides what to do next."

The whole agent, in eight lines

while not done:
    thought = model.think(question, memory, results)
    if thought.wants_a_tool:
        result = run(thought.tool, thought.input)
        results.add(result)
        if worth_keeping(result): memory.save(result)
    else:
        say(thought.answer); done = True

The model only ever chooses. Our code runs the tool and hands back the result. That's where control (and safety) lives.

Theory speaker: "Don't worry if you don't code. Read it like a recipe." Step through the lines. Land on: the AI picks, the program does. You'll see this exact loop light up in the next demo.
